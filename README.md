# ProtonCompatibilityCS
checks your steam library for games compatible with Linux via ProtonDB using c#
## WARNING

Apps not compatible due to native Linux compatibility will be marked as unknown in the code while they can be viewed at the end of the program, they won't be displayed in the main list. This separation between `borked` and `unknown` is because ProtonDB doesn't document games that do not need proton to run.

---
### installation
Simply download the repo or clone it using your terminal/shell

### requirements
Dotnet 10.0

### usage

create a copy of .env.sample and fill in your own Steam api key & Steam ID. rename it and delete `.sample` from the name
<br>A key can be generated by visiting <https://steamcommunity.com/dev/apikey>

when running the program a menu will allow you to select how you'd like to filter your games list (e.g. list only the entirely incompatible/borked games).

options are (in order of most to least compatible):
- `"Compatible"` (Returns all the compatible games; what tier they are is not specified with this mode)
- `"Platinum"`
- `"Gold"`
- `"Silver"`
- `"Bronze"`
- `"Incompatible"` (Default; Returns all the incompatible games)

After all the games for the selected filter have been printed to the console, you'll be given the option to view games that had irregular compatibility flags should there be any. 
<br>If `Y`, the list will be displayed.
<br>If `N`, the program will close.
<br>Otherwise, the program will loop until keyboard/program interrupt or a valid option has been selected.
