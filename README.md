# ProtonCompatibilityCS
checks your steam library for games compatible with Linux via ProtonDB using c#
## WARNING

Apps not compatible due to native Linux compatibility will be marked as unknown in the code and discarded. This is because ProtonDB doesn't document games that do not need proton to run.

---
### installation
Simply download the repo or clone it using your terminal/shell

### usage

create a copy of .env.sample and fill in your own Steam api key & Steam ID. rename it and delete `.sample` from the name
<br>A key can be generated by visiting <https://steamcommunity.com/dev/apikey>

currently the program only indicates what if any games are not compatible with Linux via their Proton compatibility layer
future commits will allow filtering for specific compatibility levels (e.g. Platinum)


<br>
<br>
<br>
options are (in order of most to least compatible):
- `"compatible"` (Returns all the compatible games without indicating tier)
- `"platinum"`
- `"gold"`
- `"silver"`
- `"bronze"`
- `"incompatible"` (Default; Returns all the incompatible games)
